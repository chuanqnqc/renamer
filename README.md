# FileRenamer

Desktop batch file renamer with live preview, ordered rename rules, presets, and undo.

Built with Flutter (Windows / macOS / Linux). See [plan.md](plan.md) for the iterative roadmap.

## Run

```bash
flutter pub get
flutter run -d windows
```
